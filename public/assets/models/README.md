# Licensed railway models

The application loads these optimized GLBs:

- `indian-lhb-coach.glb`
- `indian-field-engineer.glb`
- `indian-lhb-generator-car.glb`
- `indian-wap7-locomotive.glb`
- `indian-track-ballast.glb`
- `line-scan-camera-enclosure.glb`
- `mvis-project-office-portacabin.glb`

They are normalized at runtime to the scene's metre-based coordinates. Source credits and known licence links are recorded in `../ATTRIBUTION.md`. The CAM-5 enclosure and portacabin were supplied directly by the project owner; their redistribution licence must be confirmed before third-party reuse. Native procedural fallbacks remain available through React Suspense while files load.

Do not replace these assets without confirming the replacement's licence and updating the attribution record.
