## Project-owner supplied assets

The following files were supplied directly by the project owner. No external creator, source URL, or redistribution licence was included, so this record deliberately makes no licence claim.

| Intended use | Supplied file | Processing | Bundled derivative |
|---|---|---|---|
| CAM-5 under-track line-scan enclosure | `line_scan_camera_enclosure.glb` | Bundled unchanged after checksum and node-name validation | `models/line-scan-camera-enclosure.glb` |
| MVIS project office | `portacabin.zip` → `source/Portacabin .glb` | Centred at runtime; geometry and textures optimized for web delivery | `models/mvis-project-office-portacabin.glb` |

Confirm ownership and redistribution terms for these two assets before distributing them outside this project.

The original Sketchfab download archives supplied by the project owner remain at the repository root. The application also uses native project geometry and procedural materials for MVIS equipment, bogies, railway infrastructure and fallback rendering.

Any redistributed build or derivative must retain creator, source and licence attribution. Re-check the source-page licence before public release.
